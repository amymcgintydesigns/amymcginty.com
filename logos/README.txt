Put the official brand logo files in this folder, using these exact names:

  apple.svg
  ge.svg
  national-geographic.svg
  news-corp.svg
  cannes-lions.svg   (awards section, About me)

SVG or PNG (transparent background) both work; if you use PNG, change the extension in index.html.
Logos are shown in white on the colored page. Use each brand's own one-color/white version where
possible, and check any brand guidelines for recoloring. Until a file is added, the brand's name
shows as text instead.
